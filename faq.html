Getting Started & Home

Set Waymark as your launcher, choose what appears on Home, and adjust the basic Home layout.

How do I make Waymark my default Home app?

If Waymark is not currently your Home app, Home shows a Waymark isn't your Home app prompt. Tap it to open Android's launcher chooser. You can also open the same chooser from Waymark Settings at any time.

Quick way: Home → Waymark isn't your Home app → Set Waymark as your default launcher

Settings path: Waymark button → Settings → Launcher & system → Change default launcher

How do I choose which apps appear on my Home screen?

Open Home apps to choose the apps and folders you want on Home. Waymark supports up to 8 Home items; a folder counts as one item regardless of how many apps it contains.

You can also long-press an app in the app drawer and choose Add to Home or Remove from Home without opening the full Home-app editor.

Main path: Waymark button → Home apps

Quick add/remove: App drawer → long-press an app → Add to Home / Remove from Home

Is there a quick way to add or remove a single Home app?

Yes. Long-press the app in the app drawer and choose Add to Home or Remove from Home. For managing several Home items at once, use the Home apps editor from the Waymark button.

Quick way: App drawer → long-press an app → Add to Home / Remove from Home

Full editor: Waymark button → Home apps

How do I rearrange my Home apps and folders?

You can rearrange Home items in either place. Directly on Home, long-press an app or folder and drag it up or down to its new position. You can also open Home apps and drag items there.

Quick way: Home → long-press an app or folder → drag to reorder

Editor path: Waymark button → Home apps → press and drag

How do I create a folder on Home?

Open Home apps and choose the Folder option. Give the folder a name, choose the apps you want inside it, and save it. A Home folder counts as one of your 8 Home items.

Path: Waymark button → Home apps → Folder

How do I edit or delete a Home folder?

There are two ways. The quickest is to tap the folder on Home; the open folder has Edit and Delete controls at the top. You can also edit the same folder from the Home-app editor.

In the folder editor you can rename it, add or remove apps, and press and drag the apps inside the folder to change their order. Waymark asks for confirmation before deleting a folder.

Quick way: Home → tap the folder → Edit or Delete

Editor path: Waymark button → Home apps → select the folder

How do I show or hide Home app icons and names?

Use the two switches under Layout. Home app icons controls the icons, while Home app names controls the labels.

Path: Waymark button → Home settings → Layout

How do I change the size, shape or style of Home icons?

Those controls belong to the current theme rather than the Home-layout settings. Open Theme Studio and edit the icon settings there, including icon packs where available.

Path: Waymark button → Themes → Edit Current Theme

How do I use a 24-hour clock?

Enable 24-hour clock under Home behavior.

Path: Waymark button → Home settings → Behavior → 24-hour clock

How do I hide the Android status bar on Home?

Enable Hide status bar. This affects Waymark Home and is also remembered with theme-related Home appearance.

Path: Waymark button → Home settings → Behavior → Hide status bar

App controls

Settings

Change Waymark's interface, weather preferences, Android integration and launcher-wide options.

What is the difference between Home settings and Settings?

Home settings contains controls tied to Waymark Home, Waymark Now and drawer/navigation behavior. Settings contains launcher-wide options such as app appearance, haptics, weather, Android launcher controls, backup and reset.

How do I change Waymark between light and dark mode?

Open App appearance and choose System, Light, Dark or Theme. Theme allows the active Waymark theme to influence the interface appearance.

Path: Waymark button → Settings → Waymark app → App appearance

How do I turn Waymark's vibration or haptic feedback off?

Turn off Haptic feedback. This controls tactile feedback used for Waymark gestures, navigation and controls.

Path: Waymark button → Settings → Waymark app → Haptic feedback

Where are Waymark's weather settings?

Waymark uses one shared Weather settings screen throughout the launcher. You can reach it from Settings, from Waymark Hub, or directly from the settings gear on the Local forecast card in Waymark Now.

Settings path: Waymark button → Settings → Waymark app → Weather settings

Hub shortcut: Waymark button → Waymark Hub → Weather settings

Waymark Now shortcut: Swipe right to Waymark Now → Local forecast → settings gear

How do I change between Celsius and Fahrenheit?

Choose Metric for °C and km/h or Imperial for °F and mph.

Primary path: Waymark button → Settings → Waymark app → Weather settings → Units

Also: Waymark Hub → Weather settings, or Waymark Now → Local forecast → settings gear → Units

How often can Waymark update the weather?

The available update intervals are 15 min, 30 min and 1 hour.

Primary path: Waymark button → Settings → Waymark app → Weather settings → Update interval

Also: Waymark Hub → Weather settings, or Waymark Now → Local forecast → settings gear → Update interval

How do I choose which weather app opens from Waymark?

Choose Weather app and select the installed app you want Waymark to open for more detailed weather information.

Primary path: Waymark button → Settings → Waymark app → Weather settings → Weather app

Also: Waymark Hub → Weather settings, or Waymark Now → Local forecast → settings gear → Weather app

Where can I manage Waymark's Android permissions?

Choose App info. Waymark opens Android's own app-information screen, where you can review permissions, notifications, storage and battery settings.

Path: Waymark button → Settings → Launcher & system → App info

How do I restart Waymark without restarting my phone?

Use Restart Waymark Launcher. Waymark closes and immediately restarts itself.

Path: Waymark button → Settings → Launcher & system → Restart Waymark Launcher

Personalize Waymark

Themes

Use built-in themes, create your own, or edit the current look without losing Waymark's original presets.

What is the difference between Waymark Themes and My Themes?

Waymark Themes are the ready-made themes included with the launcher. My Themes contains themes you create yourself and customized versions you save. The original built-in themes remain available.

Path: Waymark button → Themes

How do I apply one of the built-in Waymark themes?

Open Waymark Themes, swipe through the ready-made themes and tap Apply Theme on the one you want.

Path: Waymark button → Themes → Waymark Themes

How do I customize the theme I am currently using?

Choose Edit Current Theme. Theme Studio lets you edit the current theme's wallpaper, colors, clock, fonts and text, icons and other appearance settings.

Path: Waymark button → Themes → Edit Current Theme

Can I create a completely new theme?

Yes. Choose Create New Theme, give it a name, customize it in Theme Studio and save it. You can find it later under My Themes.

Path: Waymark button → Themes → Create New Theme

Where are themes I created or edited saved?

Your saved themes appear under My Themes. From there you can apply, edit or delete them.

Path: Waymark button → Themes → My Themes

If I edit a built-in theme, does it permanently change the original?

No. Waymark keeps the built-in theme pristine. Your customized version is saved separately under My Themes, so the original ready-made theme remains available.

How do I delete one of My Themes?

Open My Themes and use the delete control on the theme card. Waymark asks you to confirm before permanently removing the saved theme.

Path: Waymark button → Themes → My Themes

How do I use my own photo as a wallpaper?

Open Theme Studio from either Edit Current Theme or Create New Theme, then choose the wallpaper controls and select an image from your device.

Path: Waymark button → Themes → Edit Current Theme or Create New Theme

Can I add my own font?

Yes. Open Theme Studio and go to Fonts & text. Waymark can import a font from your device and save it with your customized setup.

Path: Waymark button → Themes → Edit Current Theme → Fonts & text

Can I use an installed Android icon pack?

Yes, when a compatible icon pack is installed. Open the icon controls in Theme Studio and choose Icon packs. Waymark's own icon treatment and external Android icon packs are separate choices.

Path: Waymark button → Themes → Edit Current Theme → Icons → Icon packs

How do I change the clock style?

Open Theme Studio and edit the Clock section. The selected clock style is saved as part of the theme.

Path: Waymark button → Themes → Edit Current Theme → Clock

Will applying a theme change my Lock Screen wallpaper?

Only if you have chosen that behavior. Built-in Waymark Themes use the launcher-wide Built-in theme Lock Screen setting. Themes saved under My Themes remember their own Also use on Lock Screen choice.

Built-in themes: Waymark button → Settings → Waymark app → Built-in theme Lock Screen

My Themes: Waymark button → Themes → Edit Current Theme → Also use on Lock Screen

Home information

Waymark Hub

Control the date, weather, battery, calendar, notifications and media information shown around Waymark Home.

What is Waymark Hub?

Waymark Hub is the control center for the information Waymark can show with your Home screen, including the date, weather, battery, next calendar event, notification icons and Now Playing information.

Path: Waymark button → Waymark Hub

How do I show or hide the date, weather or battery?

Use the switches under Hub Items. Each item can be enabled or disabled independently.

Path: Waymark button → Waymark Hub → Hub Items

Why isn't weather showing on Home?

Make sure Weather is enabled in Waymark Hub and that Android has granted Waymark approximate location permission. If permission was denied earlier, open Waymark's App info and allow the required location permission.

Feature: Waymark button → Waymark Hub → Hub Items → Weather

Permission: Waymark button → Settings → Launcher & system → App info → Permissions

Can I change weather units or the refresh interval from Waymark Hub?

Yes. Waymark Hub includes a Weather settings link, and those preferences are shared throughout Waymark.

Path: Waymark button → Waymark Hub → Weather settings

How do I show my next calendar event?

Enable Next event. If Waymark does not already have calendar permission, Android will ask for it. The feature becomes enabled when permission is granted.

Path: Waymark button → Waymark Hub → Calendar → Next event

Can I choose which calendar app opens?

Yes. Choose Calendar app and select the app you want Waymark to use when opening calendar information.

Path: Waymark button → Waymark Hub → Calendar → Calendar app

How do I enable notification icons on Home?

Enable Notification icons. The first time you turn this on, Android may ask you to grant Waymark Notification access.

Path: Waymark button → Waymark Hub → Notifications & media → Notification icons

What are Persistent notifications?

When Notification icons are enabled, Persistent notifications allows Waymark to include ongoing notifications that normally remain active rather than only ordinary dismissible notifications.

Path: Waymark button → Waymark Hub → Notifications & media → Persistent notifications

Can media notifications be included with my other notification icons?

Yes. Turn on Include media notifications while Notification icons are enabled.

Path: Waymark button → Waymark Hub → Notifications & media → Include media notifications

How do I enable Now Playing and media controls?

Enable Now playing. Waymark needs Android Notification access to read active media-session information.

Path: Waymark button → Waymark Hub → Notifications & media → Now playing

How do Waymark notification previews work?

Tap a notification icon on Home to view its preview. Tap the preview to open the notification. Swipe up to close the preview without removing the notification, or swipe left or right to remove the notification.

Left of Home

Waymark Now

Configure Waymark's side page for web search, local weather and a personalized news feed.

What is Waymark Now?

Waymark Now is the page directly to the left of Home. Swipe right from Home to reach it. It can provide web search, a local forecast and news without crowding the main Home screen.

How do I turn Waymark Now on or off?

Use the Waymark Now switch. Turning the page off also stops its background updates.

Path: Waymark button → Home settings → Waymark Now → Waymark Now

Which search engines does Waymark Now support?

Waymark Now currently supports Google and DuckDuckGo.

Path: Waymark button → Home settings → Waymark Now → Search engine

What do the Search suggestions options mean?

Search engine uses live suggestions from Google or DuckDuckGo and sends partial search text to the selected provider as you type. On-device uses Waymark and your local search history without sending partial text while you type. Off disables recent-search and autocomplete suggestions while typing.

Path: Waymark button → Home settings → Waymark Now → Search suggestions

Can search results and news articles open inside Waymark?

Yes. Set Open web links to Waymark to use Waymark's built-in viewer, or choose Browser to use your default browser.

Path: Waymark button → Home settings → Waymark Now → Open web links

How do I show or hide the local forecast?

Use the Local forecast switch. The forecast provides current conditions and a 5-day forecast and uses Waymark's shared weather preferences.

Path: Waymark button → Home settings → Waymark Now → Local forecast

How do I change the news region or edition?

Open News edition. Automatic follows the device region, or you can choose another available edition.

Path: Waymark button → Home settings → Waymark Now → News edition

Can I choose what type of news appears?

Yes. Use News topics to choose one topic or mix several topics into the same feed. Waymark always keeps at least one topic selected.

Path: Waymark button → Home settings → Waymark Now → News topics

How do I stop Waymark from fetching news?

Turn off News feed. The app specifically stops fetching news when this switch is off.

Path: Waymark button → Home settings → Waymark Now → News feed

Can I manually refresh the forecast or news?

Yes. The Weather and News cards in Waymark Now each provide a Refresh control in the card header.

Where else can I find the Waymark Now settings?

Waymark Now settings are available in two places. The full controls are built into Home settings, and when the News card is visible you can tap its settings gear to open the dedicated Waymark Now settings screen.

Home settings: Waymark button → Home settings → Waymark Now

From Waymark Now: Swipe right to Waymark Now → News card → settings gear

The settings gear on the Local forecast card is different: it opens the shared Weather settings screen.

Find your apps

App Drawer & Navigation

Change the drawer layout, search behavior, hidden apps and Waymark's fast A–Z navigation.

How do I change between a list and grid app drawer?

Choose List or Grid under App drawer layout.

Quick path: Open the app drawer → tap the gear beside Search → App drawer → Layout

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → App drawer → Layout

How do I change the size of app-drawer icons?

Choose Small, Medium or Large.

Quick path: Open the app drawer → tap the gear beside Search → App drawer → Icon size

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → App drawer → Icon size

Can I hide the app names in the drawer?

Yes. Turn off Show app names.

Quick path: Open the app drawer → tap the gear beside Search → App drawer → Show app names

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → App drawer → Show app names

How do I hide an app from Waymark's app drawer?

You can hide an app directly from the drawer by long-pressing it and choosing Hide app. For managing several hidden apps, use the Hidden apps screen. Hiding an app in Waymark does not uninstall or disable it.

Quick way: App drawer → long-press the app → Hide app

Manage hidden apps: Open the app drawer → gear beside Search → App drawer → Hidden apps

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → App drawer → Hidden apps

What can I do by long-pressing an app in the app drawer?

Long-pressing an app opens App options. From there you can add or remove the app from Home, edit the name Waymark displays, open Android App info, hide or unhide the app, and uninstall it when Android allows uninstalling that app.

Path: App drawer → long-press any app

How do I make the keyboard open automatically with the app drawer?

Enable Automatic search. Waymark will focus the search box and open the keyboard when the drawer opens.

Quick path: Open the app drawer → tap the gear beside Search → Navigation → Automatic search

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → Navigation → Automatic search

How do I show recently installed apps?

Enable Recently installed. Waymark shows the 5 most recently installed apps at the top of the drawer.

Quick path: Open the app drawer → tap the gear beside Search → Navigation → Recently installed

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → Navigation → Recently installed

What is Home edge quick access?

When enabled, you can swipe along the right edge of Home to browse and launch apps by letter without first opening the full drawer.

Quick path: Open the app drawer → tap the gear beside Search → Navigation → Home edge quick access

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → Navigation → Home edge quick access

What is the Drawer A–Z rail?

In List layout, the Drawer A–Z rail lets you drag through the alphabet to jump quickly through the app list. The rail is not available while the drawer uses Grid layout.

Quick path: Open the app drawer → tap the gear beside Search → Navigation → Drawer A–Z rail

Menu path: Waymark button → Home settings → Behavior → Drawer & navigation → Navigation → Drawer A–Z rail

Can I change how long the Home A–Z rail stays visible?

Yes. Use A–Z rail timeout to choose how long the Home edge rail remains visible after you release it.

Path: Waymark button → Home settings → Behavior → A–Z rail timeout

Protect your setup

Backup & Troubleshooting

Save your Waymark setup, restore it later, reset the launcher safely, and solve the most common permission problems.

What does a Waymark backup save?

A Waymark backup saves your Home layout, folders, themes, settings, imported wallpapers and imported fonts.

Path: Waymark button → Settings → Backup & reset → Backup Waymark

How do I restore a Waymark backup?

Normally, choose Restore Waymark and select a previously saved Waymark backup file. Restoring replaces the current Waymark setup with the contents of that backup.

If Waymark has just been reset or its app data was cleared, the Welcome Back screen also provides a Restore Backup button before you begin setup again.

Settings path: Waymark button → Settings → Backup & reset → Restore Waymark

After a reset: Welcome Back to Waymark → Restore Backup

What does Reset Waymark Launcher erase?

Reset removes Waymark's layout and settings and returns the app to its first-run flow. This includes the Home layout, folders, custom themes and locally imported Waymark assets, so create a backup first if you may want them again.

Path: Waymark button → Settings → Backup & reset → Reset Waymark Launcher

What happens if I clear Waymark's app data through Android?

On an existing installation that has been reset, Waymark shows a Welcome Back screen where you can restore a backup or start fresh. Starting fresh begins the normal first-run setup again.

Weather permission was denied. How do I enable it later?

You can request weather permission again from either weather feature: enable Weather in Waymark Hub or enable the Local forecast in Waymark Now. If Android does not offer the permission prompt again, open Waymark's App info and grant approximate location manually.

Home weather: Waymark button → Waymark Hub → Hub Items → Weather

Waymark Now weather: Waymark button → Home settings → Waymark Now → Local forecast

Manual permission: Waymark button → Settings → Launcher & system → App info → Permissions

Calendar permission was denied. How do I enable it later?

Try enabling Next event again. If needed, open Android App info and allow Calendar access manually.

Feature: Waymark button → Waymark Hub → Calendar → Next event

Permission: Waymark button → Settings → Launcher & system → App info → Permissions

Notifications or media controls aren't appearing. What should I check?

First make sure Notification icons and/or Now playing are enabled in Waymark Hub. If Notification access has not been granted yet, turning either feature on will take you to Android's Notification access screen. You can also open that screen directly with the Notification access row.

Enable a feature: Waymark button → Waymark Hub → Notifications & media → Notification icons or Now playing

Direct access: Waymark button → Waymark Hub → Notifications & media → Notification access

Something in Waymark isn't updating correctly. What should I try first?

First use Restart Waymark Launcher. If the feature depends on Android permissions, also open App info and make sure the required permission or special access has not been removed.

Restart: Waymark button → Settings → Launcher & system → Restart Waymark Launcher

Permissions: Waymark button → Settings → Launcher & system → App info
